# Security Guidelines

## Goals

Protect:

- User data
- API credentials
- Local files

---

# Sensitive Data

Never:

- Log tokens
- Store passwords in plain text
- Expose secrets

---

# Storage Security

Sensitive values should use:

- Encryption
- Secure storage APIs

---

# Network Security

Support:

- HTTPS verification
- Certificate handling
- Secure connections

---

# Plugin Security

Plugins should be:

- Sandboxed
- Permission controlled
- Reviewed before installation
